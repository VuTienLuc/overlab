4 Bước thao tác Trợ lý AI

  1. 1
    Chọn định dạng: Lựa chọn loại tài liệu (Đề thi, Slide...) và theme màu mong muốn.
  2. 2
    Lên kịch bản: Dùng bảng cấu trúc chi tiết, hoặc dùng Ma trận luyện thi tự động, hoặc dán đề toán cũ vào.
  3. 3
    Lấy lệnh (Prompt): Bấm nút Cập nhật Prompt rồi nhấn Sao chép.
  4. 4
    Sinh mã LaTeX: Mở ChatGPT, Claude hoặc Gemini, dán đoạn lệnh vừa copy vào và chờ AI viết mã hoàn chỉnh.

Bí kíp chạy code trên Overleaf

  • Tạo File mới: Bấm nút Mở Overleaf, đăng nhập tài khoản, sau đó chọn nút New Project > Blank Project.
  • Chạy Code: Bôi đen và XÓA SẠCH toàn bộ code cũ trong file main.tex, dán code AI vừa viết vào, bấm tổ hợp phím Ctrl + S (hoặc nút Recompile xanh lá).
  • Lỗi Font tiếng Việt: Code đã thiết lập sẵn gói \usepackage[utf8]{vietnam}. Compiler mặc định của Overleaf là pdfLaTeX sẽ chạy mượt mà.
  • Lỗi AI vẽ hình (TikZ): Đôi khi AI vẽ hình bằng code bị sai cú pháp. Nếu biên dịch báo lỗi đỏ, hãy copy dòng lỗi đó quăng lại cho AI và bảo "Sửa lại lỗi TikZ này" hoặc "Bỏ lệnh vẽ TikZ đi, để trống khoảng trắng cho học sinh tự vẽ".
